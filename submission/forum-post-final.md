### 二、你的作品是什么

**AccessLab 是一个面向学生开发者的交互式网页无障碍学习与修复实验室。**
它不讲条文，它给你三个真的坏了的网页组件，让你自己动手修好、当场看到区别。

| 模块 | 你会经历什么 |
| --- | --- |
| **色彩对比度实验** | 正文灰 `#777777` 压在白底上，实测 **4.48:1，未达 WCAG 2.2 普通文本 AA 的 4.5:1**。点「生成修复建议」，算法算出改动最小的达标色 `#767676` → **4.54:1 达到 AA**。应用、撤销、复制 CSS 三步都能真实回退。 |
| **表单标签实验** | "姓名"那行字故意只用一个 `<span>`：屏幕上看得见，和输入框却没有任何关联。点「修复标签关联」，**DOM 真的变成 `<label for="student-name">`**：`input.labels` 从 `0` 变 `1`、点那行字能聚焦进输入框、复检问题数归 0，已输入内容一个字都不丢。 |
| **键盘焦点实验** | 请你把鼠标放到一边。三个按钮都能用键盘走到，但缺陷态的 `:focus-visible` 写了 `outline: none`——**焦点在这儿，可你看不出它在哪儿**。修复只换一条规则：`outline: 3px solid #4338ca; outline-offset: 3px`，再走一遍就看得见。 |
| **统一成果报告** | `#/report` 汇总这次会话，四项计数**分开**统计：已记录 / 已实际执行修复 / 已进行修复后复核（含人工键盘体验）/ 仍需人工验证。**不给总分、不给百分比、不给"整体合规"**。可复制或下载成 Markdown。 |

**整条动线就是：发现问题 → 动手修复 → 验证效果 → 带走代码。**
每一处数值都由页面里的算法**实时计算**（对比度走 WCAG 2.2 相对亮度公式，标签结论读自浏览器**真实 DOM**），不是写死的结论，也不是配图。

### 三、为什么做

**学生缺的不是规范文本，是"发现得了"的手段。**
无障碍缺陷不会让页面报错，也不会让测试变红。一个学生可以连着做几个学期的小项目，
从头到尾不知道自己把谁挡在了外面——**没有觉察，就没有修改的动机。**

**现有学习路径跨不过"抽象"那一步。**
读条文记住的是判定条件，不是"我这行代码会怎么影响一个人"；审计工具给一个分数和一堆报错，
照着改完仍不理解**为什么**这是障碍，而且为改一个颜色去装整套审计流水线并不现实。
AccessLab 把"读规范"换成"上手一次"：你自己调、自己看数值、自己算出那个只多 0.06 的达标色，
之后就忘不掉 4.5:1 是什么意思了。三个实验各拆掉一处理解障碍——
**看得见 ≠ 看得清**（色彩）、**有文字 ≠ 有关联**（表单）、**能走到 ≠ 能找到**（键盘）。

**成本与后果极不对称，这才是技术向善的杠杆点。**
`#777777 → #767676` 是一个字符，`<span> → <label for>` 是两个属性，删掉一条 `outline: none` 是一行 CSS，
**加起来不到十分钟**；而对另一些人，这十分钟决定这个页面他到底能不能用。
杠杆点因此不在"再多做一个审计工具"，而在**让更多人第一次动手时就顺手做对**。

**教学工具自己必须先可信。**
AccessLab 在真实浏览器的键盘事件下可以只用键盘走通，有 skip link、语义化 landmark、不跳级的标题层级、
始终可见的焦点环，`prefers-reduced-motion: reduce` 下不播动效。
一个教人别夸大结论的产品，自己最不能先夸大——所以报告页逐字写着那句"不是网站 WCAG 合规认证"。

### 四、怎么用（5 步）

> 打开链接就行，不用注册、不用装东西、不用 API Key：https://accessibility-lab-3g6uvbn5duq.qoder.zone

**第 1 步 · 首页**：首屏是主张「让网页的障碍，看得见、改得掉。」，右边那组对比数值是页面当场算的。点「开始第一个实验」。

**第 2 步 · 色彩实验**：先看到 `#777777` / `#FFFFFF` = **4.48:1 未达 AA**；
点「生成修复建议」→ `#767676` = **4.54:1 达到 AA** → 点「应用该修复」预览当场变深 → 点「撤销」回到 4.48。
顺手试试非法值 `#12zz`：旧建议立刻失效、修复区暂停，它不会拿过期结论糊弄你。

【插图：`04-contrast-before-1440.png`（4.48:1 未达 AA）+ `06-contrast-applied-1440.png`（4.54:1 达到 AA）并排】

**第 3 步 · 表单实验**：先看检测结论——"姓名"缺少关联的可见标签，而"电子邮箱"**通过**（不是一律报红）。
点「修复标签关联」，看下方前后 HTML 对比；再用鼠标点一下"姓名"那行字，焦点会跳进输入框——修复前不会。

【插图：`08-form-after-1440.png` —— `<span>` → `<label for="student-name">`，改动行高亮，展示的就是当前 DOM】

**第 4 步 · 键盘实验**：**请真的不用鼠标**，按 Tab 走过三个按钮，试着说出焦点在哪个上——说不出来，这就是缺陷态。
点「修复焦点指示」，**再按一遍 Tab**：这次有 3px 靛蓝焦点环。走完五步人工验证，点「我已完成观察」。

### 五、如何通过 Qoder 完成

2026 年 11 月 16–19 日，**四个自然日、8 个开发阶段**，单人、全程 Qoder。
分工是：**架构口径、规范解释、诚实边界由我定；实现、算法、测试、取证脚本交给 Qoder。**

| Qoder 承担的部分 | 实际做了什么 |
| --- | --- |
| **需求拆解与页面实现** | 我把"不得越界声明"写进 `PRD.md`（色彩只判普通文本 AA、结论不外推整页合规；报告不得出现总分 / 百分比 /"整体合规"）。Qoder 把它逐条变成页面行为和**可执行断言**，实现五个路由与三套实验界面。 |
| **对比度算法** | 用 WCAG 2.2 相对亮度公式实现并配单元测试。它主动指出 sRGB 线性化阈值的历史差异（`0.03928` vs 现行 `0.04045`），并说明该差异不落在任何 8 位整数通道上、对所有可选颜色结果相同——我核对规范后采纳现行值。建议色由二分逼近取改动最小者，**绝不写死**：`#777777 → #767676` 是算出来的。 |
| **DOM 标签检测** | 检测器只读浏览器真实 DOM，所以修复后复检结论会真的变化。我要求把「缺少关联的可见标签」和「完全没有可访问名称」分成两条显示，并让"电子邮箱"显示为通过——证明它不是一律报红。 |
| **键盘焦点修复与取证** | 我定的规矩：**不许拿 jsdom 的结果冒充键盘体验。** Qoder 用真实浏览器（Edge 157 / Chrome 158）+ CDP 发送键盘事件走完整条 Tab 序列，每站同时读 `getComputedStyle` 的实际 `outline` 与 `:focus-visible` 匹配。**能证明**真实内核收到按键后的焦点变化、顺序与计算样式；**不能证明**真人手按实体键盘的观感与读屏播报，这两项留在未验证清单。 |
| **Bug 迭代** | 最难的一个：五个主操作会用结果块**顶掉原按钮**，按钮消失后浏览器把焦点丢回 `<body>`——键盘用户既看不见焦点在哪，也读不到刚才那次操作的结论。功能断言全绿也看不出它，是逐站读 `activeElement` 才暴露的。修法：结果块加 `tabindex="-1"` 并主动 `focus()`，同时守住"不进 Tab 顺序 / 不新增播报区 / 位置仍在原操作区"三条边界。另两个：非法值 `#12zz` 下旧建议不失效（先补一条会失败的测试钉住再修）、文案泄漏进 CSS 产物。 |
| **组件与集成测试** | **18 个测试文件 / 295 条全部通过**，`tsc --noEmit` 干净、`npm run build` 通过，删掉 `dist/` 重建后产物哈希逐字符一致。我给 Qoder 的硬规矩：**旧测试不许删、不许跳过、不许放宽断言换全绿**；另外做变异测试——故意把算法改错，确认相关测试真的会红。 |
| **Qoder Sites 部署** | 全程同一个项目、同一个站点，没有为参赛另建域名；`lifecycle: active`、`access_mode: public`、无后端。每轮发布后用**匿名请求**核对线上实际引用的 JS / CSS 文件名并逐字节比对——「构建通过」和「公网已换成这一版」是两件事。 |

**几处是我不同意或压住 Qoder 的**：报告的"人工验证"原本只有一栏，点了"我已完成观察"就会把根本没做过的读屏验证混进同一句提示——我要求拆成三组，且每组的"（N 项）"必须等于它真正列出的条目数，数字不许手抄；导航宽屏实测 36px 被写成"未达 WCAG 要求"，我核了规范：**SC 2.5.8** 最低值是 24px，44px 属 **SC 2.5.5** 的 AAA 档建议，于是按 44px 改了（20 组视口实测一致），但措辞按规范口径修正，**不能声称小于 44px 违反 WCAG**；台账不做持久化，刷新回到 `0 / 3` 看着像缺陷，但换来"什么都不存、什么都不上传"的干净承诺。

【插图（**待补充，不得用浏览器截图冒充**）：Qoder 会话 / 任务界面截图。目前**尚未导出**；若赛事要求过程凭证，需从 Qoder 会话记录另行导出，导出前人工过一遍，避免泄露本地绝对路径与账号信息】
